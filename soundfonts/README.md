# Eingebaute SoundFont

`SoundWhacker-Auswahl.sf2` ist eine Auswahl von 45 Instrumenten aus **GeneralUser GS v2.0** von S. Christian Collins
(https://schristiancollins.com/generaluser.php). Lizenz: `GeneralUser-GS-LICENSE.txt` – erlaubt die Nutzung und
Veränderung in eigenen Software-Projekten.

Enthalten (GM-Programmnummern): Grand Piano, Tine/FM E-Piano, Celesta, Glockenspiel, Spieluhr, Vibraphon, Marimba,
Xylophon, Röhrenglocken, Orgeln, Akkordeon, Nylon-/Steel-/Clean-/Overdrive-/Distortion-Gitarre, Bässe, Violine, Cello,
Pizzicato, Harfe, Streicher, Chor, Trompete, Altsax, Klarinette, Flöte, Panflöte, Okarina, Saw Lead, Pads, Sitar, Koto,
Kalimba, Steel Drums.

Erzeugt mit spessasynth_core (Presets entfernt, ungenutzte Samples entfernt, als SF2 geschrieben).
